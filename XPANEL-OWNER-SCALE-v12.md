# v12 retained accounting owner qualification

The v11 correlated LOWER(email) ownership repair was slow on healthy synthetic SQLite: 1000rows0.126s,5000rows3.15s. v12 reads client identity and membership maps once, scans traffic in500-row pages, writes only changed owners in bounded SQL batches. Actual Go/SQLite tests: healthy1000/5000/20000rows4.5/23/95.7ms with zero UPDATEs; half-stale20000rows0.958s. Environment-specific synthetic timings, not production-scale or PostgreSQL guarantees. Membership maps use memory proportional to clients/links; exhaustive very-large or concurrent-DB qualification is not established.

Detached display owner remains -1, never a real positive inbound ID. Reader audit: email-keyed traffic mutation remains email-keyed, quota/expiry/runtime delivery/reset resolve client_inbounds membership, subscriptions join membership, and ORM ClientStats preload cannot match -1 to a positive inbound. Legacy traffic-ID/email inbound lookup tries that absent owner, then membership fallback; a truly detached client returns record-not-found instead of selecting unrelated new state. Admin operations that require an inbound may therefore refuse on detached clients. Global client operations still retain the client and history. Generic node-replacement DetachInbound remains unchanged and its existing regression passes. This is bounded source/test evidence, not exhaustive external-node or all-reader proof.

Actual v12 same-ID API reuse probe preserves old123/456 usage under-1 and only the new client appears on new inbound. Actual quota/expiry/reset and base64/JSON/Clash subscription probe passes access enforcement. Disabled/expired clients' own subscription IDs return200 and still contain their own credentials; core rejects their connection. They do not receive the healthy sibling credential. Source getSubs intentionally renders matching clients regardless of enabled state while tracking status separately. This inherited renewal-friendly representation was not changed. Do not claim disabled subscriptions are revoked, or that possessing a subscription link bypasses core enforcement. Quota is polling-based, so a connection may exceed its quota before the next poll; exact latency/overage limits were not measured. The first core traffic poll still baselines prior counters, so pre-baseline traffic is not charged.

No broad production, billing, remote accounting, transport or security claim. Prior candidates and failed harness experiments remain separate. v12 changes only repair implementation, scale tests and this note versus v11, plus generated manifests. Product source still pins original upstream and preserves attribution/license.
